# Magic Mirror Modules

This organization is a collection of modules for [MagicMirror²](https://github.com/MagicMirrorOrg/MagicMirror), however it is not an authorized part of MagicMirror².

Most repositories in this organization are currently in maintenance-only mode. We mostly try to make sure security issues are fixed and dependency updates are put in place.

If you find anything you'd like to fix or change don't hesitate to open an issue and discuss with, or - for the small stuff - feel free to drop a PR.
